# NanoJev local decision-provider evaluation

Run date: 2026-09-19. The source set is 105 hand-authored cases: 70
development cases (10 per family) and 35 untouched final cases (5 per
family). No labels were generated by NanoJev or Qwen, and development/final
rows are interleaved by family to avoid an accidental contiguous-slice
evaluation.

## Frozen-set results

| Provider | Set | Accuracy | Dangerous errors |
|---|---:|---:|---:|
| conservative deterministic baseline | final (35) | 31.4% | 4 |
| NanoJev | all (105) | 44.8% | 1 |
| NanoJev | final (35) | 45.7% | 0 |
| local Qwen one-shot classifier | final (35) | 80.0% | 0 |

NanoJev final per-family accuracy was operation 80%, progress 20%, failure
source 40%, hypothesis 40%, next investigation 40%, review finding 60%, and
completion support 40%. The deterministic baseline was respectively 20%,
40%, 40%, 20%, 20%, 40%, and 40%. NanoJev's final-set multiclass Brier score
was 0.6103 and ECE 0.1897; these are reported as model distributions, not
calibrated probabilities. Its all-set Brier/ECE were 0.6100/0.1180.

## Runtime

The local CPU provider loads one 2.385 GB float32 `best.safetensors`
checkpoint (596,250,498 parameters) and uses no GPU memory. A persistent
50-call run measured 16.2 s startup, p50 0.527 s, p95 0.548 s, batch-8
0.466 s/question, about 5.36 GiB resident RAM, and about three CPU cores.
The 105-case run measured p50 0.548 s, p95 0.699 s, 76.1 s inference time,
and no swap activity.

## Real controller comparison

The same deliberately broken greeting fixture was run twice against the same
local Qwen service. Controller-only completed in about 15.8 s with four Qwen
requests. NanoJev `advisory` (still enforced as shadow-only because the
provider is not trusted) completed in 36.8 s with the same four Qwen requests
and one NanoJev decision. Both produced the correct edit, passed the frozen
test, and had no unsafe duplicate action or human intervention. The added
decision did not save a Qwen call or reduce work; its cost was the model
startup/decision latency.

These are bounded repair results, not evidence of long-session convergence.
No authority was granted to NanoJev, and no real mutation was routed by it.

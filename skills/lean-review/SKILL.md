# Lean review

1. Inspect the actual diff, callers, generated files, and current state.
2. Check correctness, data loss, secrets, rollback, and accidental scope.
3. Compare claims with observed commands and independent evidence.
4. Preserve historical facts without treating them as current authority.
5. List residual risks and the smallest follow-up needed.
